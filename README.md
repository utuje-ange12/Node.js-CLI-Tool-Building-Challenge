# TaskMate CLI

A simple command-line task manager built with Node.js.

## Setup

```
npm install
```

## Usage

```
npm start -- add "Buy milk"
npm start -- list
npm start -- done 1
npm start -- delete 1
```

Tasks are stored in `data/tasks.json`.

## Scripts

- `npm start` runs the app
- `npm run dev` runs the app and restarts on file changes
